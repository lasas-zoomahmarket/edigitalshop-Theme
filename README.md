# eDigital Shop — ثيم توسّع المخصص

ثيم Twig مخصص لمتجر **eDigital Shop** (قوالب إكسل/وورد/بوربوينت/PDF جاهزة) على منصة **توسّع**، مبني فوق [قالب توسّع الرسمي](https://twsaa.com) (twig-theme-main).

## بنية المشروع

- `views/` — كل قوالب Twig الفعلية للثيم (الهيكل العام، الصفحة الرئيسية، الفئات/المنتجات، صفحة المنتج، السلة، صفحات حساب العميل). هذا هو المحتوى الذي يُسلَّم لمنصة توسّع.
- `assets/css/custom.css` — نظام التصميم الكامل للثيم (الألوان، الخطوط، كل عناصر الواجهة). يُحمَّل تلقائيًا بعد ستايلات توسّع الأساسية عبر `layout/main.twig`.
- `src/Twig/` — إضافات Twig الحقيقية من توسّع (الدوال، الترجمة) كما هي من القالب الرسمي، بدون أي تعديل.
- `composer.json` / `composer.lock` — متطلبات Twig.
- `index.php`, `data.php`, `_local_preview_router.php` — **أدوات معاينة محلية فقط للتطوير**، وليست جزءًا من الثيم المُسلَّم لتوسّع. تستخدم بيانات تجريبية لعرض كل صفحة محليًا أثناء التطوير (`php -S 127.0.0.1:8899 _local_preview_router.php`). منصة توسّع تزوّد القوالب ببياناتها الحقيقية مباشرة عبر نفس أسماء المتغيرات والدوال.

## الصفحات المحوَّلة

- الهيكل العام: الهيدر والفوتر (`layout/header.twig`, `layout/footer.twig`)
- الصفحة الرئيسية بكل أنواع البلوكات الحقيقية (بانر، فيديو، تقييمات العملاء، مميزات المتجر، العلامات التجارية، شبكات/سلايدرات المنتجات)
- صفحات الفئة وكل المنتجات (مع التحميل اللانهائي الحقيقي)
- صفحة المنتج — قالب واحد موحّد يدعم كل أنواع المنتجات الحقيقية (بسيط، قابل للتحميل، بخيارات/variants، بخيارات تخصيص، حجوزات)
- السلة وملخص الطلب
- كل صفحات حساب العميل (الطلبات، العناوين، المفضلة، المنتجات القابلة للتحميل، المحفظة، الإشعارات، الملف الشخصي)

## ملاحظة مهمة

كل منطق البيانات والمسارات والدوال الحقيقية من قالب توسّع الرسمي محفوظ تمامًا بدون أي تعديل وظيفي — التحويل اقتصر على التصميم المرئي (CSS) وبعض إعادة ترتيب العناصر، فوق الهيكل الحقيقي نفسه.
